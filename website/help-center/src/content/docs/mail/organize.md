Use **Group mail from one sender** in **Settings** > **General** to gather a sender's read messages into one row. Open the row to see the individual emails. [Mark the current list as read](/mail/mark-read/) includes mail inside groups.

## Select several emails

Use `Ctrl+click` to pick separate emails or `Shift+click` for a range. You can drag selected messages onto a folder or choose an action for the selection.

For a keyboard-only selection in Rukoo's shortcut scheme:

1. Move the focus ring with `Ctrl+Down` and `Ctrl+Up`.
2. Press `Ctrl+Space` on each email you want. Press it again to remove that email from the selection.
3. Choose Archive, Delete, Move, Move to category, mark read or unread, or Star. The action applies to the selected emails.
4. Use the following notice or `Ctrl+Z` to undo an archive, delete or move. Press `Esc` to clear a selection.

`Enter` opens the email in the focus ring and clears the selection. Expand a sender group with the right arrow to select individual messages inside it.

On macOS, move the ring with `Command+Up` and `Command+Down`, then select with `X` or `Control+Space`. Use `X` if macOS reserves Control+Space for input sources. Gmail's scheme uses `X`; shortcut schemes have their own bindings.

If the mail server refuses a move or delete, Rukoo reports the failure. Check the result before repeating a bulk action.
