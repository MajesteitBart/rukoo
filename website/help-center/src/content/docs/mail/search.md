Use the search field in the title bar to find mail by text.

## Search your mail

1. Open the folder or account you want to search.
2. Enter your search in the title-bar search field.
3. Choose **This folder**, **This account** or **All accounts** as the search scope.
4. Select a result to read it.

The results include older mail on the server as well as mail kept on your computer. Server results need a connection to your mail provider. On a plain IMAP server, the search checks subjects, senders and To/Cc addresses. Gmail also searches message text, except in Spam and Trash.

## Narrow the list

Use **Unread**, **Starred** or **Attachments** above the message list to filter it. A quick filter can narrow a search too.

A category hidden from Inbox still appears in search. [Inbox category switches](/mail/category-switches/) explains the difference between a hidden category and a notification setting.
