Mark the mail currently shown in the message list as read.

## Choose the mail first

Open a folder or category and select an account. Apply a search or a quick filter if you want to narrow the list. Check the results before continuing.

## Mark the list as read

1. Open **More options** above the message list.
2. Choose **Mark all as read**. You can also press `Shift+Esc`.
3. Read the notice to check how many messages were marked.

The action includes messages folded into sender groups. With the **Unread** filter on, the list empties except for the email you have open.

## Undo it

Choose **Undo** in the notice, or press `Ctrl+Z`. On macOS, use `Command+Z`.

If the mail server refuses some changes, those messages stay unread. The notice reports how many were marked, and Undo covers those messages.
