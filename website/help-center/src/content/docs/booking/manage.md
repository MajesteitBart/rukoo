Use the computer that handles your [booking page](/booking/how-it-works/). Keep Rukoo running so changes can reach your calendar and guests.

## Accept or decline a request

1. Open the request in **Calendar**, or under **Requests** in **Settings** > **Booking page**.
2. Check the guest and time. A request holds that time on your page and appears as a dashed **Request** block in the calendar.
3. Select **Accept** to create the event and send the calendar invitation, or **Decline** to free the time.
4. If you add a message, check whether **Also email this message from …** is on. It is off by default. The message appears on the guest's confirmation page either way.

Only the handling computer can answer requests. An unanswered request expires after 48 hours or at its start minus the minimum notice, whichever comes first.

## Move a confirmed booking

Drag its event to the new time in Rukoo, or move it in your calendar provider's app. Rukoo carries the new time to the booking and the guest's confirmation page. Check the event after syncing.

Resizing the calendar event leaves the booking's original duration in place. The card then says **Length changed in your calendar**.

## Cancel a confirmed booking

1. Open the event's card or the booking in the bookings list.
2. Select **Cancel booking**.
3. Read the confirmation and any message you add, then confirm.

Your calendar sends the cancellation. Deleting a booked event in another calendar app, or the guest declining its invitation, also cancels the booking when Rukoo next checks.

## Links the guest uses

The invitation's description contains **Pick another time** and **Cancel booking**. These links open the guest's own booking page. Anyone who has them can move or cancel the booking, so take care when forwarding an invitation or adding someone to the event.

The guest can move a booking twice. Changes made while the handling computer is off reach your calendar when it runs again.
