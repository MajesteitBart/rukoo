Start with a [connected agent](/agents/connect/) and **Permission level** set to **Ask**. Use an email you are comfortable sharing with that agent and its provider.

## Ask for the draft

1. Open the email you want to answer.
2. Open the agent panel with the sparkle button in the title bar.
3. Start a new chat and check the email chip above the input. It names the email that will go to the agent with your first message.
4. Choose **Draft a reply**, or type `/reply` and send it. Add your own instruction if the reply needs a particular answer or tone.
5. Read the draft in the composer. Check the recipients, facts, quoted content and attachments.
6. Edit it, then select **Send** when ready.

The agent's draft card has **Undo** if you want to take the draft back. Sending follows your [Undo send setting](/mail/undo-send/).

## Ask without the open email

Before the first message, select the email chip's close button to leave that email out. **Add this email** brings it back. A started chat keeps its email; start a new chat for a different context.

The agent may still use its mail-reading tools. The chip controls what accompanies that message.

## Check an action card

With **Ask**, Rukoo shows a card before a mail action such as archiving or unsubscribing. Read what will change before accepting. A proposal to update another system lets the agent carry out that change after you approve it.

Messages and attachments from other people can contain misleading instructions. Keep approvals on while checking how the agent handles your mail, and review drafts yourself.
