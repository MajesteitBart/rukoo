A Rukoo account syncs Rukoo's settings across devices and signs you in to team chat. Have an invite code from your server's operator ready if that server requires one.

## Create the account

1. Open **Settings > Rukoo account**.
2. Check **Server**, who runs it and where its data is stored. Use the server your team has chosen if you want to join its workspace.
3. Choose **Create an account**.
4. Enter your email address, a password of at least 12 characters, and **Repeat password**.
5. If **Invite code** appears, enter the code supplied by the operator. A workspace invitation link also works when that server permits it.
6. Tick the confirmation about password recovery and choose **Create account**.
7. On **Save your recovery key**, save the key in a password manager or another safe place. Rukoo shows it once.
8. Choose **I saved it**.

Your computer starts syncing its Rukoo data. Keep both your password and recovery key: the key is the only way back into the account if you forget the password.

## If the server refuses sign-up

A server can require an invite code or close new registrations. Ask its operator for access. If a workspace invitation is refused as an invite code, ask for an operator-issued code.
