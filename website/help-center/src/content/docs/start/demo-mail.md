In this short lesson, you will open a demo inbox and read a sample email. The demo account contains English sample mail and a sample calendar.

## Before you start

Install Rukoo Mail 2.4.0 on a desktop computer and open it at the **Set up email** screen. Use the English interface for the labels below. The demo account needs no credentials.

## Open the demo inbox

1. On **Set up email**, select **Try a demo account first**.
2. Select **Inbox** in the sidebar. You will see the sample messages.
3. Select a message in the list. Its subject and contents appear in the reading pane.

You have opened and read your first demo email. When you switch folders, Rukoo can display the newest message automatically; it stays unread until you open it yourself.
