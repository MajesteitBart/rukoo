Inbox categories sort mail inside Rukoo. Other mail apps still see the same server inbox.

## Set up categories

1. Open **Settings** > **General** > **Inbox categories** on desktop, or **Settings** > **Inbox categories** on Android.
2. Enable categories if needed. Start with Needs you, To read, Money, Updates and Promotions, or edit their names, descriptions and colors.
3. Put overlapping categories in priority order. When several fit, the higher one wins. You can have up to twelve.
4. Set **When Rukoo isn't sure** to the category that should receive uncertain mail.

A description tells Rukoo what belongs in that category. Make it specific enough to distinguish it from the others.

## Correct an email

Right-click an email and choose **Move to category**. For several selected emails, use More. On Android, press and hold the email, or use More in the open email.

The following notice offers **Also future mail**. Choose it to put future mail from that sender in the same category. Remove that sender rule in Settings when it is no longer useful.

**Sort the inbox again** applies sorting again while keeping emails you moved yourself. With a Rukoo account, category definitions and corrections sync across devices.

## Optional model sorting

Jev can sort mail the rules are unsure about. It needs your own TypeSafe API key in category settings. On that device, it sends the sender, subject, first 1,000 characters, some header facts and your category descriptions to TypeSafe in the United States. Review that choice before adding a key. Categories also work through local rules without Jev.

[Show in Inbox and Notifications](/mail/category-switches/) control where category mail appears and whether it alerts you.
