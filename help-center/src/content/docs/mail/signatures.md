Open **Settings** > **Signatures** to see the general signature and the signature used by each account.

## Set the general signature

1. Open **General signature**.
2. Write your name and contact details, or paste a signature from another mail app.
3. Use the editor's formatting controls for links, bold text, colors or images. **Edit HTML** opens the HTML source if you need it.
4. Save and check the preview on the Signatures page.

The general signature applies to accounts that use it. Each account's row shows whether it uses the general signature, its own signature or none.

## Give an account its own signature

1. On **Signatures**, open the account's signature.
2. Enter and save the signature that account should use. Choose **Use general signature** when it should follow the shared one again.
3. Start a message and check **From** and the signature together.

All sender addresses and aliases of one account share that account's signature. Choose a separate signature per account when your work and personal mail need different details.

Images inserted in the signature are sent as inline attachments; images from the web remain web links. The plain-text version of the email carries the signature as text.

If you have a [booking page](/booking/set-up/), **Booking link under signature** adds its link below the signature. Keep `{url}` in any custom text so Rukoo can insert the address.
